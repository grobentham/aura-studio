# Release hardening audit — increment 1
Scope: local project persistence, portable export, track ownership, long canvas rendering, tool discovery and recent CI. Not an exhaustive security or hardware audit.
- P0: package backup used to await a forced database save; a conflict/quota failure could prevent the recovery export. Export now takes a stable metadata snapshot without requiring a project DB write. Existing stored assets are retained byte-for-byte, streamed assets verified, missing decoded assets exported from memory in PCM24 with bounded fallback allocation. Missing unrecoverable assets are still rejected. No format change.
- P0: giant timeline/clip canvases could exceed browser maximum dimensions and memory. Backing store limited to 8192 per dimension and 8 MiPixels per canvas, preserving CSS logical coordinates; long waveform sampling capped at 4096 columns. Reduced resolution on exceptionally long timelines is intentional; viewport virtualization remains needed for sharp labels and scalable DOM.
- P1: tools overflowed a fixed menu. Existing action nodes grouped, searchable, scrollable and keyboard launchable; no commands removed.
- P0 open: first Stem Splitter CI run intermittently failed short archive capture; same commit passed the full subsequent run. Root cause unproven. Physical capture stress and journal interruption tests remain release gates.
- P0 open: imported legacy JSON asset ID collision and missing-asset policy need a dedicated migration/compatibility review; cross-tab concurrency and storage eviction need fault injection. Avoid modifying existing project schema without fixtures.
- P1 open: full timeline virtualization, memory budgets for decoded import and long sessions, full-length mastering, real trained model, Safari/Firefox/mobile and hardware validation, offline update lifecycle, listening tests. Commercial readiness not established.
Tests: new Chromium hardening checks for large canvas, export with failed project save and missing stored audio, and grouped search navigation. Existing regression suites retained.
