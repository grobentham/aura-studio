# Aura Analyse Pro

Local worker analysis for selected melodic MIDI clips, short audio/streamed clips or audible mix from playhead. FFT spectral peaks with approximate harmonic suppression generate chroma, ranked major/minor key profile fits and coarse two-second triad hypotheses. Energy-rise transients yield ranked periodic pulse candidates (including half/double-time ambiguity), not verified downbeats. Audio quality measures sample peaks, RMS, clipping, quiet intervals and stereo correlation. Coarse changes in energy/harmony suggest possible section boundaries, not automatic verse/chorus classification. MIDI uses duration-weighted pitch classes, bar-level chord candidates, note-gap phrase ranges and out-of-scale notes; these are not necessarily errors. Explicit apply key/BPM, ordinary undo, no audio retiming or automatic arrangement modification. Max audio excerpt 30 seconds; no external requests. Synthetic fixtures and browser regression only; real-recording corpus accuracy and more sophisticated beat tracking remain outstanding. Shared pure API is available for subsequent composition engines.
