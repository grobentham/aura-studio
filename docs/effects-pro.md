# Effects Pro
19 native insert types, eight per track. Legacy high/low-pass, trim and saturation remain compatible. New notch, parametric bell, shelves, configurable native compressor and peak compressor, soft distortion, amplitude quantization (not sample-rate reduction), tremolo, chorus, flanger, bounded feedback echo, deterministic stereo convolution room, width and pan. Each module has bounded primary and secondary parameters and uses the same graph for live and offline. Modulation oscillators are owned and stopped on graph disposal. Echo feedback is limited to 0.65. Five factory starting chains, 32 local user chains, JSON import/export, undo. Native compressor latency, modulation phase and effect tails are not automatically compensated; peak compressor is not certified true-peak limiting. No sidechain input, dedicated transient shaper, expansion/gating or plugin host in this release. Listening, long-duration tail and high-load evaluation remain open.
