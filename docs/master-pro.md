# Aura Master Pro

Local 48 kHz offline mastering preview, 0.4–30 seconds including tail. The existing gain-only export remains available. The processor renders the current mix without the default master compressors, then uses three complementary broad bands, stereo-linked envelope compression, conservative warm/bright/reference balance, M/S width, gated loudness gain and 4x interpolated peak lookahead limiting with post-process remeasurement and safety gain. The peak estimate is NOT a certified true-peak meter. No linear-phase crossover or professional conformance claim. Reference balance uses broad band energy shares, not genre or artistic inference. A/B preview matches estimated loudness with peak safety. Export supports deterministic TPDF-dithered 16/24-bit WAV. No project mutations.

Known limits: short preview rather than full-length mastered export; reference input capped by file size and decoded excerpt duration; no standards corpus evaluation or listening tests yet. Node fixtures and Chromium integration cover loudness, bounded peaks, correlation, reference gains, dither, preview and export. Future: official conformance fixtures, sustained mastering, improved crossover and listening evaluation.
