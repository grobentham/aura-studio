# Aura Stem Splitter
Two independent modes. Offline spectral separation uses STFT, time/frequency median masks and overlap-add; harmonic estimate plus residual percussive estimate reconstructs the source. This is not vocal/drum/bass isolation. Reference: Fitzgerald (2010), Harmonic/Percussive Separation Using Median Filtering; https://librosa.org/doc/main/api/generated/librosa.decompose.hpss.html.
Experimental four-stem model adapter: use a locally obtained, compatible single-session htdemucs_fp16weights.onnx described at https://github.com/StemSplit/demucs-onnx/blob/main/docs/browser.md. Fixed mix [1,2,343980], stems [1,4,2,343980], 44.1 kHz, drums/bass/other/vocals. Do not use specialist FT files. No weights redistributed; verify source and license before redistribution. Explicit consent downloads pinned ONNX Runtime Web 1.20.1 from jsDelivr (third-party runtime, not bundled or offline-cached). WASM single-thread worker, 25% overlap, shape/finite checks, cancellation via worker termination and five-minute timeout. Actual model inference and real-song separation quality not validated; adapter unit fixture uses a mock inference tensor, not learned weights. No remote audio API. Model mode requires network for runtime unless browser cache suffices; untrusted model files may consume excessive resources. Only load trusted weights. Source audio <=20 seconds, derived tracks muted by default, independent persisted assets, one undo. No full-song or GPU performance claims.
