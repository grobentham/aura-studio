# Instruments Pro
Versioned bounded patch schema stored on each synth track; optional local preset library (64 entries), JSON import/export, patch audition and one-step undo. Native Web Audio per-voice subtractive dual oscillators, frequency modulation, harmonic-table morph using PeriodicWave, additive partials, and deterministic Karplus–Strong-style plucked-string buffers. ADSR, filter envelope, velocity-sensitive cutoff, vibrato and filter LFO. Existing factory presets and sampler remain unchanged. Wave morph is static per note, not a continuous scan. Pluck is a short generated model, not an acoustic multisample. No granular sample engine, modulation matrix or sophisticated global voice stealing yet. Unit and Chromium tests check sound generation and project integration; actual music listening and high-polyphony performance are outstanding.
