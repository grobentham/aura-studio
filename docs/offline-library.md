# Sound Library Pro and offline
Personal samples use separate IndexedDB records with metadata and canonical PCM24 WAV blobs. Up to 20 seconds, 12 MiB per sample, 128 entries/128 MiB total. Search, tags, type, BPM metadata, favorites, attribution field, preview and independent project copies. Save selected audio to library; portable .aurasounds packs reuse the bounded binary package framing but have distinct sample metadata. Import validates all entries before a single transaction. No automatic loop matching or commercial sample redistribution license. 
Opt-in service worker caches exact local shell URLs, worker modules and SoundTouch dependencies; no cross-origin fetch interception. Factory recorded audio remains on existing download-on-use cache; clearing it doesn't touch project or personal library. Install availability depends on browser. Manual offline enable/update and close all tabs for activation. Every shell-changing release must bump RELEASE and update the exact versioned URL list in sw.js; tests check actual network-disabled Chromium reload. Browser eviction still possible; backup externally. Cloud requires network.

The Node regression checks every exact versioned local HTML dependency appears in the shell and every listed file exists. Sample packs are rejected by project restore with a dedicated explanation. Browser-side caching of new app releases requires version bumps as documented above.
