# Compose Pro
Custom 1–12 sections, up to 128 bars; major/minor key, pop/dance/gentle/soul rule sets, seed, energy and humanization controls. Seven diatonic degrees, optional seventh chords, dynamic programming progression fitted to a selected MIDI motif, bounded inversion/voice-leading search, six editable roles (melody, keys, bass, drums, counter, pad). Without a motif, melody follows generated chord tones. Regenerate one planned section before appending; other sections remain unchanged. Generated tracks are appended as one undoable operation. Uses Analyse Pro for generated harmony review. This is procedural MIDI, not audio generation, not trained genre models or guarantees of professional arrangements. No audio requests. Listening evaluation and editing previously committed sections remain outstanding.
